## Summary

Packaged devmemory for free public distribution via GitHub + uv tool install, with install.sh, new CLI commands (status/doctor/explain/memory query/scan), LICENSE, docs, and CI.

## Why

User wants the tool free to use, distributed via a public GitHub repo, with an AgentOS-inspired onboarding UX (curl|bash install, uv tool install --from git+..., a richer top-level command surface).

## Rejected alternatives

Literal 'devmemory context explain' and reusing 'status' for the repo-overview command -- both collided with commands already built the same day (context --file/--symbol/--profile; status <id> <new_status>). Resolved by adding a separate 'devmemory explain' command and renaming the old mutation command to 'set-status', not by breaking either.

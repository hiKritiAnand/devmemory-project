## Summary

Split scan() into two passes: definitions then resolution

## Why

Resolving SQL table references (and any cross-file resolution) depended on alphabetical file iteration order within one scan batch, silently failing when a referencing file sorted before the file defining what it referenced

## Rejected alternatives

A single pass with the existing per-file loop; broke whenever two related files changed in the same commit
